# FLP Course App

Sell recorded courses and live classes to students.

| Folder | What |
|---|---|
| [`flp-mobile-app/`](flp-mobile-app) | Student app — React Native CLI 0.88 (Android first) |
| [`flp-api-admin/`](flp-api-admin) | API (Fastify) + admin panel (React + Vite) |
| [`docs/superpowers/specs/`](docs/superpowers/specs) | Requirements / design spec |
| [`docs/superpowers/plans/`](docs/superpowers/plans) | Implementation plans, one per phase |

Services: Supabase (Postgres + Auth), Bunny (video + files), Razorpay (payments), Zoom (live classes).
